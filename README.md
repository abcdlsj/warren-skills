# `@abcdlsj/warren-skills`

Agent Skills for Warren workspace and session management.

## Included skills

- `warren` — resource semantics, worked examples, and anti-patterns for Warren
  tasks, projects, workspaces, Agents, sessions, pane arrangements, and
  endpoints.

## Install

From the GitHub skill source:

```sh
npx skills add abcdlsj/warren-skills
```

Or install the packaged skill files from npm:

```sh
npm install @abcdlsj/warren-skills
```

The skill definition is at `skills/warren/SKILL.md`.
